# AX Hub UX 시나리오 설계서

기준: `public/index.html` + `public/js/app.js`. 날짜: 2026-08-11.

## 1. 사용자

| 페르소나 | 목적 | 기본 권한 |
|----------|------|-----------|
| 공유 열람자 | 현황·지식을 링크로 본다 | 읽기. 등록/저장/삭제/이관/현황 업데이트 없음 |
| 관리자 (컨설턴트) | 라이브러리를 쌓고 대시보드를 동기화 | 비밀번호 → 12시간 토큰 |

기본 진입은 **공유 모드**. 사이드바 상태가 「공유 모드」이고 쓰기 버튼은 숨겨진다.

## 2. 정보 구조

```
AX Hub
├ 홈 / 통합 대시보드
├ 과제 Library          목록 ↔ 상세
├ 프롬프트 Library      목록 ↔ 상세
├ Vibe Coding Library   목록 ↔ 상세(문서 탭 5)
└ Best Practice Library 목록 ↔ 분석 폼 ↔ 상세(+원본 뷰어)
```

좌측 고정 내비 5개. 뷰 전환 시 상단 eyebrow/title이 바뀐다.

| 뷰 | eyebrow | title |
|----|---------|-------|
| 홈 | 통합 현황 | 메인 홈 / 통합 대시보드 |
| 나머지 | Knowledge | 각 Library 이름 |

상세는 같은 뷰 안에서 목록 패널을 숨기고 상세 패널을 연다. 「← 목록으로」로 복귀.

## 3. 공통 패턴

- **목록 카드**: 제목 + STATIK 경로(또는 분야·태그) + 한 줄 요약. 카드 클릭 = 상세.
- **STATIK 필터**: L1→L4 종속. 「전체」로 초기화. 과제·프롬프트·Vibe 동일.
- **빈 상태**: 「조건에 맞는 …가 없습니다」/「불러오는 중…」/에러는 `.status-msg.error`.
- **확인**: `alert`/`prompt`/모달. 로그인·Gemini 키는 `prompt`.
- **잠금**: 공유 모드에서 상세 입력은 읽기 전용 스타일, 단계 삭제 버튼 숨김.

## 4. 시나리오

### 4.1 공유 열람 — 홈

1. URL 진입 → 공유 모드, `GET /api/hub-summary`.
2. KPI: 총 협력사, 총 참여자, 총 과제수, 평균 진척도.
3. 과제별 요약: 정렬(협력사/난이도/과제명). 체크박스·「과제 Library로 등록」없음.
4. 병목 및 리스크: 일정 대비 진척 정체. 건수는 헤더 helper.
5. 「과제 현황 업데이트」는 관리자만 상단 액션에 나타남.

### 4.2 관리자 — 현황 동기화·이관

1. 사이드바 「관리자 로그인」→ 비밀번호 → 토큰 저장, 「관리자 모드」.
2. 홈 상단 「과제 현황 업데이트」→ 소스 재조회 + hub 미러.
3. 미이관 과제 체크 → 「과제 Library로 등록」. 이미 이관된 항목은 체크 불가.
4. 「관리자 로그아웃」→ 공유 모드 복귀.

### 4.3 과제 Library

**목록**

- 건수, STATIK 필터, 관리자 「과제 등록」.
- 카드: 제목, L1>L2>L3>L4, 협력사·난이도 등.

**등록/상세**

1. 등록: 빈 폼. 필수 과제명.
2. 기본: 난이도(상/중/하), 담당자 수, 기간(개월 자동), 협력사, 목표.
3. STATIK L1~L4 → 브레드크럼.
4. AX 성과지표 8칸(AS-IS/To-Be 분, 절감, 절감률, 빈도, 연간 시간, FTE, 자동화율).
5. As-Is / To-Be: 단계 추가(이름·방법·도구·시간 등) + 세로 플로우 미리보기.
6. 저장 PATCH/POST. 공유 시 편집 불가, 조회만.

### 4.4 프롬프트 Library

1. 필터·목록·「프롬프트 등록」(관리자).
2. 제목*, 태그, 설명, 변수(비우면 `[변수명]` 추출), STATIK, 본문*.
3. TXT 선택 시 본문·원본 파일명 채움. 제목 비었으면 파일명.
4. 저장. 공유는 읽기.

### 4.5 Vibe Coding Library

1. 목록·필터·「문서 등록」.
2. 제목*, 태그, 설명, STATIK.
3. 탭: readme.md / 개발 계획서 / UX 시나리오 설계서 / UI 디자인 설계서 / 기타.
4. 탭마다 직접 입력 + TXT. 저장 시 **문서 최소 1개** 필수.
5. 탭 전환은 로컬, 저장은 묶음 단위.

### 4.6 Best Practice Library

**목록 (공유·관리 공통)**

- 검색: 제목·태그·요약·개선효과. 건수 표시.
- 「전체 리스트 보기」로 검색 초기화.
- 카드: 제목 / `분야 · 태그1, …` / 요약 140자 / 개선효과.
- **파일 형식(이미지·PDF)은 목록에 내지 않음.**

**관리자 등록**

1. 「문서 분석 등록」→ 점선 패널.
2. PDF 또는 PNG 선택(분야 셀렉트 없음).
3. 「Gemini로 요약 등록」. 키 없으면 안내.
4. AI 결과: 개조식 본문, 분야 11택일, 키워드 5개, 원본 Storage.
5. 목록 새로고침 후 상세로 이어질 수 있음.

**상세**

- 분야는 helper 텍스트.
- 관리자: 제목·태그·주요내용·Before/After·개선효과 수정 후 저장. 삭제.
- 원본: PDF iframe 또는 PNG `<img>`. 없으면 빈 메시지.
- 제목만 수정해도 태그는 유지(AI 태그 보호).

**Gemini 키**

- Best Practice 뷰 상단 「Gemini API Key 등록」. 저장 API는 관리자만. 공유 클릭 시 로그인 안내.

## 5. 권한 매트릭스

| 행동 | 공유 | 관리자 |
|------|------|--------|
| 홈 KPI·과제·리스크 보기 | ○ | ○ |
| 과제 현황 업데이트 | × (버튼 없음) | ○ |
| Library 목록/상세 보기 | ○ | ○ |
| 이관·등록·저장·삭제 | × | ○ |
| 문서 분석 등록 | × | ○ |
| Gemini 키 저장 | × | ○ |

## 6. 예외

| 상황 | UX |
|------|----|
| API 실패 | 목록 영역 빨간 상태 메시지 또는 alert |
| 파일 형식 오류 | 「PDF 또는 PNG만」/「TXT만」 |
| 15MB 초과 | 서버 `파일 크기는 15MB 이하여야 합니다` |
| Gemini 키 없음 | 503 메시지, 키 등록 유도 |
| Gemini JSON 필수값 누락 | 502, 빠진 필드명 |
| 이미 이관된 과제 | 체크 비활성 |
| 비밀번호 오류 | 401, alert |
